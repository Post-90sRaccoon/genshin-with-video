# Menu Bar Toggle Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this small change in the current feature branch. Use test-driven-development and verification-before-completion for the checks below.

**Goal:** Hide and restore the top menu bar through a configurable global shortcut and the existing context menu.

**Architecture:** Add a persisted boolean and a ninth hotkey to existing settings. Route menu and hotkey commands through one controller action, and derive the top content inset and button visibility in layout. Preserve the bottom status strip and use it as a drag area.

**Tech Stack:** C++17, Win32, libmpv, existing PowerShell build.

**Spec:** `docs/superpowers/specs/2026-11-05-menu-bar-design.md`

## Global Constraints

- Default visible; Ctrl+Alt+M is the default global toggle.
- No new dependencies or changes to playback intent and outer window bounds.
- Preserve all five/eight legacy custom bindings and resolve appended-default conflicts.
- Keep context-menu recovery, bottom playback information, dragging and resizing usable.

## Review Focus

- Starting with saved hidden state must hide every button before the window is shown.
- Changing DPI while hidden must not restore the top inset or button visibility.
- An occupied toggle shortcut must still allow recovery through the context/tray menu.
- Toggling during playback or while the window is hidden must preserve media and pause intent.
- All nine settings controls must fit above the login fields.
