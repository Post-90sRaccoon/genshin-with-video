# 倍速播放设计

用户要求从 develop 新建功能分支，为 B 站视频增加倍速播放。

- 使用现有 C++ / Win32 / libmpv，不增加依赖。分支为 `codex/feature-playback-speed`，按用户要求在当前目录开发。
- 开发者选择的档位为 0.5、0.75、1、1.25、1.5、1.75、2 倍，默认 1 倍；使用 libmpv 的 `speed` 属性并显式启用 `audio-pitch-correction`。
- 顶部增加显示当前倍速的按钮，点击弹出原生单选菜单；右键提供相同的“播放速度”子菜单。工具栏在最小窗口宽度和 DPI 缩放下仍完整可用。
- 设置保存全局倍速，旧配置默认 1 倍，非法、非有限值或不支持的档位回退到 1 倍。
- 调整倍速不重载、不跳转、不改变暂停状态。新视频、切换分 P、手动重试、地址续期与设置引起的播放器重建都应用当前倍速。
- 观看进度和前后跳转继续使用视频时间；地址有效期继续使用真实时间。沿用现有热键。

## 实现方案

现有 libmpv 已支持同步调整音视频速度，是这项功能直接可用的实现。自行逐帧或重采样需要重复实现同步与音调处理，没有必要。界面采用顶部直接入口加原生菜单；仅放设置里每次操作较多，新增常驻滑条则增加小窗布局负担。以上界面与档位是开发者在常规功能范围内的默认选择，可按用户后续反馈调整。

## 验证

先验证旧配置兼容和持久化，再验证真实控制器菜单命令及最小宽度布局；使用本地媒体按墙钟测量 0.5 与 2 倍的进度推进，检查暂停、跳转、重新载入；最后使用实际 B 站视频检查倍速音视频播放。完成构建并提供可直接运行的便携程序。

## 快捷键扩展

用户随后要求添加变速快捷键。沿用 RegisterHotKey，默认 Ctrl+Alt+[ 减一档、Ctrl+Alt+] 加一档、Ctrl+Alt+0 恢复 1 倍，均可在设置修改。上下限钳制在 0.5 / 2 倍，保持暂停/隐藏状态，弹窗内忽略全局操作。旧版五项按键按原顺序迁移为八项并保留用户设置；若新默认值与旧自定义冲突，为新增动作选未使用的 Ctrl+Alt+Shift+F1…F11，设置中显示实际结果。新增按键沿用冲突提示与注销生命周期。
