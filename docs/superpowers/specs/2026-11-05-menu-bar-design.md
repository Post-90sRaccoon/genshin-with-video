# 菜单栏显示切换

用户希望熟悉快捷键后可以隐藏菜单栏，并用快捷键随时切换。

本次将“菜单栏”解释为顶部六个按钮及拖动区。默认显示；隐藏后视频区域向上扩展，窗口位置和外部尺寸保持不变，底部播放信息保留。底部状态栏可用于拖动窗口，边缘仍可缩放。

默认全局快捷键为 `Ctrl+Alt+M`，可在设置中修改。右键菜单和托盘菜单提供带选中状态及当前快捷键的“显示菜单栏”入口。切换立即保存，重新启动恢复上次状态，不改变播放、暂停、倍速、鼠标穿透及整个小窗的显示状态；弹窗期间沿用现有快捷键保护。

实现沿用 Win32、现有设置存储与热键注册，不增加依赖。五项及八项旧快捷键配置保留原绑定并补齐新动作；默认键冲突时沿用现有后备键规则。

实现选择：仅隐藏顶部按钮区；同时隐藏底部信息超出本次菜单栏需求。自动悬停显隐会增加非用户触发的状态变化，本次采用明确的按键/菜单切换。以上默认快捷键和状态栏拖动是实现时采用的默认选择。

验收覆盖旧配置迁移、保存恢复、真实 HWND 控件显隐和视频布局、96/144/192 DPI、全局热键注册/注销/冲突、弹窗保护及真实 libmpv 播放状态不变。
