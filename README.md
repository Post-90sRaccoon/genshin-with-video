# 原神攻略小窗

Windows x64 原生悬浮播放器。粘贴 B 站链接或 BV 号，选择分 P，在游戏旁边播放。C++ / Win32 界面，libmpv 播放，yt-dlp 按需在线解析。

旧版 EXE 曾被 Windows Defender 隔离，微软尚未确认误报。退出原因调查见 `docs/crash-investigation.md`，各版本测试记录见 `docs/verification.md`。

## 下载

播放时会自动更新即将到期的音视频地址，长时间暂停后继续播放会检查地址有效期，并保留进度。针对 15:55 画面冻结的调查与验证见 `docs/playback-freeze-investigation.md`。

👉 [前往下载 Windows x64 便携版](https://github.com/Post-90sRaccoon/genshin-with-video/releases)

进入发布页面，展开对应版本的 **Assets**，下载其中的 Windows x64 便携 ZIP 压缩包。

**Source code (zip)** 和 **Source code (tar.gz)** 是源码包，不包含可直接运行的完整程序。

下载后完整解压，打开文件夹中的 `GenshinVideo.exe`。
如果游戏以管理员权限运行，请先退出小窗，再通过 `Start-GameMode.cmd` 启动。

## 使用

打开解压目录中的 `GenshinVideo.exe`，点击 **打开**。**选集**可切换路线，每个视频、每个 CID 分别保存进度。位置、尺寸和观看进度保存在程序旁的 `data` 文件夹。移动时请保留整个便携目录，目录需要可写。

**本机原神以管理员权限运行，请先退出已有小窗，再双击 `Start-GameMode.cmd`，确认 Windows UAC。** 这个入口让小窗以相同权限启动，启动后入口进程会退出。直接双击 EXE 使用普通权限，适合游戏也以普通权限运行的情况。若重复打开游戏模式入口，会提示先退出正在运行的小窗。

| 默认快捷键 | 操作 |
| --- | --- |
| F8 | 暂停 / 继续 |
| F9 / F10 | 倒退 / 前进 5 秒 |
| Ctrl+Alt+[ | 减速一档（最低 0.5×） |
| Ctrl+Alt+] | 加速一档（最高 2×） |
| Ctrl+Alt+0 | 恢复 1× |
| F7 | 隐藏并暂停 / 显示并保持暂停 |
| F6 | 开关鼠标穿透 |
| Ctrl+Alt+M | 显示 / 隐藏顶部菜单栏 |
| Ctrl+O / Ctrl+P / Ctrl+, | 打开 / 选集 / 设置（小窗前台时） |

拖动上方空白区域移动，拖动四边或四角等比例缩放视频区域。拖动上、下边缘时宽度会同步变化，窗口左侧保持不动；达到最小尺寸后停止缩小。右键菜单提供重试、从头播放、上一 P / 下一 P、退出。托盘图标可显示并解锁窗口，重新启动相同目录的程序也可找回窗口。

缩放按窗口可见边缘限制在当前显示器内，可紧贴屏幕四边，也可覆盖任务栏区域；继续向内拖动即可缩小，松手后保存最终位置。普通拖动仍可将小窗移动到其他显示器；显示器断开后，会将越界小窗移回屏幕内。

熟悉快捷键后，可按 **Ctrl+Alt+M** 隐藏顶部菜单栏，也可在小窗或托盘图标的右键菜单中切换 **显示菜单栏**。隐藏后保留底部播放信息，拖动底部状态栏即可移动窗口。切换不影响播放，程序会记住菜单栏状态；再次按快捷键或通过右键菜单可恢复。快捷键可在 **设置 → 菜单栏显示 / 隐藏** 中修改。

点击顶部的 **1×**（当前倍速）按钮，或右键 → **播放速度**，选择 **0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×**。底部播放信息也会同步显示当前倍速。调整立即生效，启用音调校正，暂停时调整仍保持暂停。倍速会保存，切换分 P、重试、更新播放地址及下次启动都会沿用。进度和前后跳转仍按视频时间计算。

变速和菜单栏快捷键为全局按键，可在 **设置 → 快捷键** 中修改；发生按键占用时会提示。旧版五项或八项快捷键会保留并补上新增动作；如果旧自定义按键已占用了新默认值，新增动作会选用空闲组合键，实际结果以设置窗口为准。

在 **设置** 中调整按键、360p / 480p / 720p 画质上限及音量。选流优先上限以内的 H.264、约 30 fps 及以下视频，允许帧率元数据最多 0.1 fps 的偏差。按键冲突会提示，解除热键不可用时不能开启鼠标穿透。公开画质以每次实际返回为准，720p 上限不代表所有视频匿名可获取 720p。

登录信息为可选的 Netscape 格式 `cookies.txt` 文件，只保存所选文件路径；不自动读取浏览器账户，不提供内嵌登录。具体画质仍取决于账号的播放权限。

## 游戏与资源

优先使用窗口化 / 无边框游戏模式。独占全屏覆盖需要实际验证。程序使用 Windows 全局热键，不读写游戏进程、不自动操作游戏。

默认前向压缩包缓存 16 MiB、回退缓存 8 MiB，均不是整个进程的内存上限；DLL 磁盘大小也不是运行占用。实测结果见 `docs/verification.md`。画质直接影响解码开销。

## 命令行与构建

```powershell
& .\dist\GenshinVideo\GenshinVideo.exe 'https://www.bilibili.com/video/BV1BMgj6MEz4/?p=2'
```

源码构建需要 Visual Studio C++ Build Tools（已验证 VS2017 14.16）、Windows 10 SDK 和 PowerShell：

```powershell
.\scripts\setup-deps.ps1
.\scripts\build.ps1
.\scripts\build.ps1 -TestOnly        # 核心策略
.\scripts\build.ps1 -IntegrationOnly # 存储、网络句柄、控制器
.\build\integration.exe --network    # 实际音视频解码
.\tests\diagnostics_tests.ps1       # 退出证据关联回归
.\scripts\run-app.ps1 -WaitSession  # 持续运行，退出后收集本次原因
```

依赖读取 `deps.lock.json` 并校验 SHA256，不自动换成最新版本。缓存完整时可离线校验。输出为 `dist/GenshinVideo`。源码和依赖许可、来源见 `LICENSE`、`THIRD_PARTY.md` 和 `licenses`。

`integration.exe --network` 打开的是临时验证窗口，测试结束后会主动关闭。日常使用请打开上面的 `GenshinVideo.exe`。正式程序的 `data/session.jsonl` 只记录时间、进程号和事件，不记录视频地址或登录信息。

### 画面卡住时保存现场

正式版 `GenshinVideo.exe` 默认保存播放器警告/错误摘要，并每 2 秒记录播放与音频时钟、主视频缓存、暂停/跳转/缓冲状态、丢帧及实际解码方式。属性不可用时记录空值和错误码。快进、快退、重试和重新加载前后会留证；记录不能单独证明画面持续刷新。

发现视频输入在正常片尾前异常结束时，新版会保存现场，并尽量利用尚未播完的缓存，在后台准备新连接；准备期间原播放器继续播放，准备完成后从最新位置切换，保留分 P 和倍速。暂停、隐藏或菜单/弹窗操作期间会推迟切换；手动跳转、换集或修改设置会作废旧任务。不会因普通重试警告、正常片尾或已经完整缓存的 EOF 重新加载。

后台准备最多等待 30 秒；如果缓存先耗尽，会暂时停住音频，避免声音继续跑远。准备失败时仍保留原来的重新取流恢复，每次人工打开或手动重试最多自动换源两次，反复失败后保留有用进度并提示手动重试。后台解析只临时运行 yt-dlp，仍只有一个常驻播放器；故障报告会记录耗时、缓存余量、进程树峰值提交内存和安全的来源域名，不记录完整取流地址或登录信息。

下次发生「画面不动、声音继续」时，先右键 → **保存故障现场**，记下弹窗显示的报告位置，再重试当前分 P。报告位于程序旁的 `data/diagnostics/reports`，保存最近约 10 分钟的有界记录和当前取流上下文，不改变播放进度或暂停状态。即使重试已恢复，先前的日志仍可提供线索。

日志只在本地保存，包含 BVID、分 P、播放位置和 CDN 主机名等播放信息。Cookie、Authorization、完整播放地址、签名参数和原始提取结果会被过滤。日志文件每份至多 2 MiB，保留 3 份；报告保留最近 5 份。写入失败或队列溢出会记录诊断健康计数，不据此中断播放。采集脚本也可按时间、PID 和会话筛选这些记录。

如需单独生成 `GenshinVideo-diagnostics.exe`，可从源码运行 `.\scripts\build.ps1 -DiagnosticsBuild -NoPackage`，输出位于 `build` 目录。
